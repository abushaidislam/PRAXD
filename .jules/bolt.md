## 2026-10-31 - Memoizing Sidebar List Items Under High-Frequency Drag & Selection Events
**Learning:** In PRAXD's split-view workspace architecture, the sidebar features continuous drag resizing (updating `sidebarWidth` and tooltip coordinates on mousemove) as well as frequent PR selection via keyboard navigation or click. Without `React.memo` on `PullRequestListItem`, every mouse move during drag and every PR selection triggered complete re-renders of all PR rows in the inbox. Memoizing `PullRequestListItem` drops selection re-renders from O(N) to O(1) (only the previous and new selected item re-render), preventing jank and keeping frame rates high.
**Action:** Always wrap leaf list items in `React.memo` when rendered inside interactive or resizable container panels, and verify that parent callbacks passed down (e.g., `onSelect`) maintain stable function identities.
